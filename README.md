# Лабораторная работа: Обработка массивов

## Автор
Карнаухов Фёдор (Вариант 7)

## Цель
Освоение базового синтаксиса C++ и работы с двумерными массивами на примере формирования новой матрицы путем удаления заданной строки и столбца.

## Описание
Программа формирует из заданной квадратной матрицы V новую матрицу W. Матрица W получается путем удаления из матрицы V k-ой строки и k-ого столбца (вычисление минора).

## Исходные данные
Пользователь вводит с клавиатуры:
- Размерность исходной матрицы V.
- Элементы исходной матрицы V (построчно).
- Номер k строки и столбца, которые нужно удалить.

## Ожидаемые результаты
Программа выводит:
- Исходную матрицу V в общепринятом табличном виде.
- Полученную матрицу W, размер которой на 1 меньше исходной, в общепринятом табличном виде.
